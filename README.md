# Astrology study cards

Mobile flashcards for astrology study. One page, five decks:

- Signs (12)
- Planets (10)
- Elements (4, plus the 6 blends)
- Houses (12, plus an overview card)
- Modes (3)

Tap to flip, swipe or use Prev and Next to move, and tap a rail button to jump. The page remembers the last deck and card.

Content follows the study guides kept alongside this project. When a card and a study guide disagree, fix both.
